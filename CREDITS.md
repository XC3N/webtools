# Credits

UX & features design by XC3N · implementation & coding by Claude.

The code is written for these tools rather than copied from other projects, apart from the vendored library below. What they borrow is listed here, and the list is updated in the same commit as whatever adds to it. VJif and Bad MOPHO have their own lists in their repositories ([VJif](https://github.com/XC3N/VJif/blob/main/CREDITS.md), [Bad MOPHO](https://github.com/XC3N/BadMOPHO#credits)).

## Code

- [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) 5.2.2 by Vanilagy (MIT), in `common/vendor/`: VJif writes its MP4 recordings with it (VJif builds with a pinned copy).

## Typefaces

- Glyph Viewer: draws the glyphs of unscii-8 mcr by Viznut ([unscii](https://github.com/viznut/unscii), public domain / CC0; none of its Unifont-derived files are used) as a sprite sheet, and shows the Sprawler game's tile sheet, which is drawn from them.
- Interface: Instrument Sans and JetBrains Mono (JetBrains), from Google Fonts (SIL Open Font License).
