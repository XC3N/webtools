# Credits

UX & features design by XC3N · implementation & coding by Claude.

The code is written for these tools rather than copied from other projects, apart from the vendored library below. What they borrow is listed here, and the list is updated in the same commit as whatever adds to it.

## Code

- [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) 5.2.2 by Vanilagy (MIT), in `common/vendor/`: VJif writes its MP4 recordings with it.

## Typefaces

- Interface: Instrument Sans and JetBrains Mono (JetBrains), from Google Fonts (SIL Open Font License).
- VJif Lettering: Russo One, Anton, Bebas Neue, Bungee, Monoton, Orbitron, Press Start 2P, Rubik Mono One, Righteous (SIL Open Font License) and Permanent Marker (Apache License 2.0), from Google Fonts.
- VJif's TV › Channel number: [VCR OSD Mono](https://www.dafont.com/vcr-osd-mono.font) 1.001 by Riciery Leal (MrManet), free for any use, commercial included; embedded as a subset of the TTF (the characters the number uses).

## Data

- VJif Colour › Palette: the C64 colours are Philip "Pepto" Timmermann's palette (pepto.de); the CGA, EGA, NES and Game Boy colours as listed in Wikipedia's "List of video game console palettes".

## Ideas

- The Dissolve › Melt transition follows the Doom screen wipe (id Software, 1993).
- CRT › Pay-TV follows analogue cable sync suppression; Crypt follows Videocrypt's cut-and-rotate and Nagravision Syster's line shuffling.
- Ordered dithering uses Bayer's matrix (Bryce Bayer, 1973).
